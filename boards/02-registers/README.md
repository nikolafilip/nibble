# Board 02: registers

The three 4-bit registers on the bus: A and B (the ALU's operands) and OUT
(the display). 366 transistors, 198 resistors, 12 LEDs.

| | |
|---|---|
| Bus signals used | in: BUS0#..BUS3#, CLK, AI, AO, BI, BO, BA, AB, OI. out: A0..A3, B0..B3 (register contents, for the ALU and the panel) |
| Bus driven | BUS0#..BUS3# open-drain when AO (A) or BO (B) |

Every register is four master-slave D flip-flops. A two-phase non-overlapping
clock derived from CLK (D033) makes the masters transparent while CLK is low
and copies them to the slaves on the rising edge. In front of each bit an
AND-OR mux chooses what the flip-flop captures:

- A takes the bus when AI, B when AB, otherwise holds.
- B takes the bus when BI, A when BA, otherwise holds.
- OUT takes the bus when OI, otherwise holds.

AB and BA together exchange A and B in one clock (XCH): both masters capture
the old values before the edge, both slaves change after it. A, B and OUT are
not on the reset line; they power up in whatever state the latches fall into,
and programs must write a register before reading it.

## Files

- `registers.kicad_sch`: the board, generated by `sim/build_registers.py` from `sim/registers.py`. Do not hand-edit.
- `registers-testbench.kicad_sch`: clock, control stimulus, diode bus drivers, 5 V supply and hub pull-ups so the KiCad simulator runs out of the box. Excluded from the board and BOM.
- `registers.kicad_pcb`, `fab/`: layout by `sim/pcb.py`.

## Verification (2026-09-10)

Schematic gate: `sim/tb_registers.py` runs a 113-step clocked script on the
kicad-cli export: every value through A and B from the bus, A and B driven back
onto the bus, MOV, XCH, OUT, and holds while the bus changes.

| Netlist | Corner | Result |
|---|---|---|
| kicad-cli export | TYP, LO, HI | 113 / 113 each |
| gate list | MIX seeds 1, 2, 3 | 113 / 113 each |

Machine gate: `fib.asm` on ALU + hub + registers, 127 ticks, 0 mismatches at
TYP, LO, HI and MIX (see `sim/gate.py` output in the commit that added this board).

Reproduce from `sim/`:

```
python3 build_registers.py
kicad-cli sch export netlist --format spice -o out/reg/registers_kicad.cir ../boards/02-registers/registers.kicad_sch
python3 tb_registers.py out/reg/registers_kicad.cir out/reg --corner HI
python3 machine.py programs/fib.asm --boards alu,hub,reg --corner MIX --seed 2
```
