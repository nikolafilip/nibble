# Board 03: sequencer

The control unit: step counter, instruction and operand registers, flags, two
decoders and the diode control matrix. 524 transistors, 298 resistors, 83
matrix diodes, 19 LEDs. The program counter and the return register are on
board 09 (D035).

| | |
|---|---|
| Bus signals used | in: M0..M7, CF, ZF, CLK, RST. out: II, PCE, SUB, EO, AI, AO, BI, BO, BA, AB, OI, IO, PCL, FI, HLT, MAI, MI, MO, ONE, F0, F1, INP |
| Bus driven | BUS0#..BUS3# open-drain with OPR3..0 while IO (LDI, LOAD n, STORE n) |
| Link header (2x6) | to board 09: OPR0..OPR7, PCR, RAI, GND, GND |

How it runs an instruction (docs/isa.md):

- **Steps** are a one-hot ring of five flip-flops with asynchronous reset. S0
  loads IR and the operand's low nibble (`II`); S1 counts (`PCE`); S2, only for
  a two-word instruction, loads the second word (`OPI`, `PCE`); S3 and S4 drive
  the matrix rows. The `DONE` column returns the ring to S0.
- **IR and OPR** are transparent latches open while their load line and PH1
  are both high: they follow the memory word during the low half of the clock
  and are closed before the rising edge on which everything else changes.
- **Decoders**: IR3..0 to OP0#..OP15#, OPR3..0 to F0#..F15#, each through a
  pair of 2-to-4 predecoders so no NAND has more than two transistors in series.
- **Rows**: `NOR(OPn#, T3N)` for every opcode, `NOR(OP0#, Fn#, T3N)` for every
  family member, an S4 row for the four memory accesses, and for JC and JZ a
  second row that includes the latched flag. 37 rows, 10k pull-ups.
- **The matrix**: a diode from a row to a column pulls that control line high
  while the row is active. 23 columns with 1 Meg pull-downs: 19 go to the bus
  header, `PCL` too, `PCR` and `RAI` to the link, `DONE` back to the step ring.
  New instructions are diodes; rows OP8..OP15 are free.
- **Flags**: CFQ and ZFQ latched from the ALU while `FI` and PH1.

## Files

- `sequencer.kicad_sch`: generated by `sim/build_sequencer.py` from `sim/sequencer.py`. Do not hand-edit.
- `sequencer.kicad_pcb`, `fab/`: layout by `sim/pcb.py`. The matrix is laid out transposed: rows are vertical tracks at 3.81 mm pitch on the back, columns horizontal tracks at 10.16 mm on the front, a diode standing on each populated crossing.
