# Board 04: program memory

16 words of 8 bits on DIP switches: one page of the 256-word program space.
112 transistors, 69 resistors, 17 LEDs, 16 DIP-8 switches, 128 diodes.

| | |
|---|---|
| Bus signals used | in: PC0..PC7. out: M0..M7 through diodes (the hub holds M low; several pages OR together) |
| Headers | two 64-way, wired pin for pin in parallel (D039): the hub's ribbon on the left one, the next page's on the right one. Every line is carried, not only PC and M |
| Size | 216 x 250 mm (12 mm wider than the switch array needs, so both shrouded headers and the corner hole fit along the top edge) |

- **Word select**: PC3..0 through a 4-to-16 decoder.
- **Page compare**: four jumpers, one per bit of PC7..4. Pins 1-2 mean "this
  page has a 1 in that bit", pins 2-3 a 0. All four on 2-3 is page 0
  (addresses 0 to 15). PAGE = all four match.
- **Rows**: ROWn = word n selected and PAGE, 10k pull-ups. An LED per row
  shows the word being fetched.
- **Switches**: word n's DIP-8 has the row on one side and a diode from each
  switch to its M line on the other. Closed = 1. Bit 7 is the top switch (the
  top bit of the opcode); blank memory reads 0000 0000 = NOP.

More program space is more copies of this board, each strapped to its page
(D019), daisy-chained with 10 cm ribbons from one page's right header to the
next page's left header; only the first page runs a cable to the hub (D039).
`python3 sim/asm.py programs/<name>.asm` prints the switch pattern per word.

Generated by `sim/build_program.py` from `sim/program.py`; it also writes
`program.map.json` (which diode is which word and bit) so the machine
simulation can close the switches for a program. Machine gate: every program,
with the behavioural memory model replaced by one copy of this board per page.
