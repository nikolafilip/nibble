# Board 06: front panel

The test fixture and the face of the machine. 50 transistors, 42 LEDs, 50 resistors.

- **Level switches** (three DIP-8): A3..A0, B3..B0, and the 14 control lines. A closed switch connects the line to +5 V through 10k, so a switch left on can never fight a board that pulls the line low; it only supplies a 1 where nothing else drives.
- **Data switches** (DIP-4): pull BUS0#..BUS3# to ground directly, exactly like an open-drain driver. Closed = 1 on the bus.
- **CLK and RST buttons**: RC debounce, an NMOS Schmitt trigger (two inverters, 1 Meg feedback), 10k and a diode onto the line. One press = one clean edge at every threshold corner (simulated with contact bounce). The clock board can drive the same lines later.
- **1 Meg pull-down** on every switched or observed line, so a line reads 0 when no board drives it.
- **An LED on every line**: 38 bus lines directly, plus the four data bits through inverters so the LED shows the data, not the active-low wire.

Order 1 test with hub + panel + ALU: set A, B, SUB, EO on the switches; read S on the data LEDs and CF/ZF.
