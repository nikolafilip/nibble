# Board 06: front panel

The test fixture and the face of the machine. 80 transistors, 56 LEDs, 72 resistors.

- **Level switches** (four DIP-8): A3..A0, B3..B0, and the 24 control lines. A closed switch connects the line to +5 V through 10k, so a switch left on can never fight a board that pulls the line low; it only supplies a 1 where nothing else drives.
- **Data switches** (DIP-4): the input port. A closed switch is a 1; while `INP` is high the four bits are driven onto the bus through the usual NAND and open-drain transistor, which is how the IN instruction reads them. To force the bus by hand, close the INP switch too.
- **CLK and RST buttons**: RC debounce, an NMOS Schmitt trigger (two inverters, 1 Meg feedback), 10k and a diode onto the line. One press = one clean edge at every threshold corner (simulated with contact bounce). The clock board can drive the same lines later.
- **1 Meg pull-down** on every switched or observed line, so a line reads 0 when no board drives it.
- **An LED on every line**: 52 bus lines directly, plus the four data bits through inverters so the LED shows the data, not the active-low wire.

First test with hub + panel + ALU: set A, B, SUB, EO on the switches; read the result on the data LEDs and CF/ZF.
