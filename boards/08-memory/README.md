# Board 08: data memory

16 slots of 4 bits with its own address register. 747 transistors, 287
resistors, 68 LEDs: one per cell, so the memory is visible.

| | |
|---|---|
| Bus signals used | in: BUS0#..BUS3# (an address while MAI, data while MI), MAI, MI, MO, CLK |
| Bus driven | BUS0#..BUS3# open-drain with the addressed slot while MO |

- **Address register**: four transparent latches open while `MAI` and PH1. A
  memory instruction puts the address on the bus for its whole S3 tick (B for
  `LOAD [B]`, the operand for `LOAD n`), so the latch closes on it before the
  edge.
- **Decoder**: MAR3..0 to W0#..W15# through 2-to-4 predecoders. Per slot a
  write line WR = slot and `MI` and PH1, a read line RD = slot and `MO`.
  The write is gated by PH1 so it ends at the clock edge, before `MI` and
  the bus change (D037): the first design let the write line outlast the
  data by a few microseconds, and at the mixed-threshold corner the write
  stacks flipped cells with the next tick's bus data. The shared MI line has
  a 4.7k pull-up so the sixteen write lines drop within microseconds.
- **Cell**: two cross-coupled inverters. While WR, the bus data forces it:
  D pulls QN low (a 1), BUS# itself pulls Q low (a 0). While RD and Q, a
  two-transistor stack pulls the bus line low (reads a 1). Eight transistors,
  two resistors, one LED per bit; 512 transistors in the array.
- **No reset**: memory keeps its contents through RST and powers up random.
  Programs write before they read.

Generated by `sim/build_memory.py` from `sim/memory.py`.

Schematic gate: `sim/tb_memory.py` writes every slot three times (slot
number, its complement, a scrambled pattern), reads everything back, and
interleaves single writes with reads of untouched slots: 217 steps, the bus
and the control lines changing at the same instant, which is the worst case
the machine only approaches at some corners. The kicad-cli export passes
217/217 at TYP, LO, HI and mixed-threshold seeds 1 to 3. The board as first
drawn failed 47 steps at every corner.

```
kicad-cli sch export netlist --format spice -o out/mem/memory_kicad.cir ../boards/08-memory/memory.kicad_sch
python3 tb_memory.py out/mem/memory_kicad.cir out/mem --corner MIX --seed 2
```

Machine gate: `list.asm`, `mul.asm`, `sort.asm`, `lfsr.asm`, `calc.asm`,
`logic.asm`, `call.asm` (see `sim/gate.py`).
