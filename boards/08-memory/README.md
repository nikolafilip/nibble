# Board 08: data memory

16 slots of 4 bits with its own address register. 746 transistors, 287
resistors, 68 LEDs: one per cell, so the memory is visible.

| | |
|---|---|
| Bus signals used | in: BUS0#..BUS3# (an address while MAI, data while MI), MAI, MI, MO, CLK |
| Bus driven | BUS0#..BUS3# open-drain with the addressed slot while MO |

- **Address register**: four transparent latches open while `MAI` and PH1. A
  memory instruction puts the address on the bus for its whole S3 tick (B for
  `LOAD [B]`, the operand for `LOAD n`), so the latch closes on it before the
  edge.
- **Decoder**: MAR3..0 to W0#..W15# through 2-to-4 predecoders. Per slot a
  write line WR = slot and `MI`, a read line RD = slot and `MO`.
- **Cell**: two cross-coupled inverters. While WR, the bus data forces it:
  D pulls QN low (a 1), BUS# itself pulls Q low (a 0). While RD and Q, a
  two-transistor stack pulls the bus line low (reads a 1). Eight transistors,
  two resistors, one LED per bit; 512 transistors in the array.
- **No reset**: memory keeps its contents through RST and powers up random.
  Programs write before they read.
