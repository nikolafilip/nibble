# Board 09: counter

The 8-bit program counter and the 8-bit return register. 416 transistors, 221
resistors, 16 LEDs. Split off the sequencer for board size (D035).

| | |
|---|---|
| Bus signals used | in: PCE, PCL, CLK, RST. out: PC0..PC7 |
| Link header (2x6) | from board 03: OPR0..OPR7 (jump target), PCR (load the return address), RAI (save the return address) |

- **PC**: eight master-slave flip-flops with asynchronous reset. Each bit's
  input is PC xor carry (count when `PCE`, hold otherwise), OPR when `PCL`
  (JMP, JC, JZ, CALL) or RA when `PCR` (RET). The count carry ripples through
  seven AND gates.
- **RA**: eight transparent latches open while `RAI` and PH1. CALL asserts
  `RAI` and `PCL` in the same tick: RA captures the old PC during the low half
  of the clock, PC loads the target on the rising edge that follows.

Generated by `sim/build_counter.py` from `sim/counter.py`; verified with the
machine gate together with board 03 (see its README).
