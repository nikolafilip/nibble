# Decision ledger

Append-only. One row per decision, newest at the bottom. `Story` says what it
changes for the public log (the X account brain lives in a separate repo and
reads this file). IDs never change; a reversed decision gets a new row.

| ID | Date | Decision | Why | Story |
|---|---|---|---|---|
| D001 | 2026-08-17 | Hand-build a 3-bit sign-magnitude add/subtract calculator in RTL (2N3904, 10k/22k/4.7k) as a learning exercise. | Relearning electronics from nothing. | The origin. Posted as-is, bugs and all. |
| D002 | 2026-09-09 | Extend the calculator with a sequential multiplier/divider, simulation only. | Test whether an AI can work at schematic level. | 480 extra transistors, 256/256 exhaustive pass. Not built. See `experiments/muldiv/`. |
| D003 | 2026-09-09 | The goal is a 4-bit CPU, built as separate boards, in public. Multiply/divide dropped from the roadmap. | 4-bit CPUs multiply in software; the experiment served its purpose. | "Nibble". |
| D004 | 2026-09-09 | Logic family: NMOS with 2N7000 and one pull-up resistor per gate. | D005 | 2026-09-09 | Through-hole parts, hand-soldered, board size unconstrained. | Nikola wants to solder every joint. | Joint count is a recurring number. |
| D006 | 2026-09-09 | Number representation: 4-bit two's complement. The sign-magnitude converter is gone. | Subtraction becomes "invert B, add 1". Both known bugs of the origin lived in the converter. | Educational post: why computers use two's complement. |
| D007 | 2026-09-09 | Accumulator architecture: registers A, B, OUT, IR, PC; flags C and Z; ten instructions (see `isa.md`). | D008 | 2026-09-09 | Program memory is a grid of DIP switches with one diode per bit. The CPU cannot write it. | Zero transistors instead of about 1,500 for flip-flop RAM. Reprogrammed by flipping switches. Filmable. | Altair-style front panel. |
| D009 | 2026-09-09 | Boards connect with 50-way ribbon cables to a bus hub board and sit in a rack, not stacked on headers. | A stack of pass-through headers gets wobbly past 4 boards; a rack looks better on camera. | The rack shot. |
| D010 | 2026-09-09 | Bus lines are open-drain, active-low, pulled up on the hub. | NMOS gives a shared bus for free; no tri-state logic needed. | One sentence on wired-OR buses. |

| D012 | 2026-09-09 | Decision ledger lives here. The X repo's own ledger points at IDs from this table. | One source of truth for engineering; the story repo reads, never rewrites. | |
| D013 | 2026-09-09 | Fab order 1 grows to four boards: coupon, ALU, front panel, bus hub. | The ALU and panel need the hub's power entry and bus pull-ups; the hub is the cheapest board. | Four boards in one order. |
| D014 | 2026-09-09 | Panel switches drive lines through 10k to +5 V; buttons through a diode; every line has a 1 Meg pull-down. | A switch left on can never fight a board that pulls low (NMOS pulls low through a few ohms). No "manual mode" switch needed. | One sentence on wired-OR. |
| D015 | 2026-09-09 | No power switch on the hub; the USB plug is the switch. | No suitable through-hole switch in the standard library; fewer parts. | |
| D016 | 2026-09-09 | PCB style: one tile per cell (pull-up on top, transistors in a column), 10.16 to 15.24 mm column pitch, power pre-routed as rails on the back, signals autorouted (freerouting), ground pour on the back. | D017 | 2026-09-10 | Bus header is 2x32 (64 pins). Adds PC4..7, BO, MAI, MI, MO, PWL, PWH and four spares over the 50-pin version. | D018 | 2026-09-10 | Program counter is 8 bits; jumps are two-word instructions (opcode word, then an 8-bit address word); an 8-bit operand register on the sequencer. | 4-bit data does not mean 4-bit addresses (the 4004 had 12-bit ones). 16 words is a demo ceiling; 256 words costs about 160 transistors once. | Educational post: data width vs address width. |
| D019 | 2026-09-10 | Program memory boards are pageable: PC0..3 select the row, PC4..7 are compared with four jumpers, M0..7 are diode-OR across boards. | D020 | 2026-09-10 | Data memory (scratch RAM) is a separate future board: 16 slots x 4 bits, its own address register loaded from the bus (MAI), MI/MO lines. Opcodes 1011 LOAD n and 1100 STORE n reserved. | The address coming from the bus lets a loop use B as a pointer (needs BO) so programs can walk lists. Fixed-address LOAD cannot. | Multiply, divide, sort become programs, not boards. |
| D021 | 2026-09-10 | Control board is a diode matrix: 16 opcodes x 2 execute steps = 32 rows, one column per control line plus DONE, 1 Meg pull-downs, holes at every crossing, ten instructions populated at assembly. | Adding an instruction is soldering diodes, not a new board. The instruction set is readable off the board. Same technology as the program memory. | The microcode-as-diodes post. |
| D022 | 2026-09-10 | Sequencer has five states (fetch, increment, optional second fetch, execute 1, execute 2) with early DONE. One-word instructions stay at 3 ticks. | Memory access needs two execute ticks; two-word jumps need a second fetch. | |
| D023 | 2026-09-10 | B register gets a bus output (BO). | Memory pointer for loops. Four transistors. | |
| D024 | 2026-09-10 | Whole-machine simulation against a Python emulator is the acceptance test for every board, before and after fab. Boards for order 2 are designed and pass it before order 1 is placed. | So that order 1 cannot be invalidated by something learned while designing the sequencer. | The "it ran Fibonacci in ngspice before copper existed" post. |
| D025 | 2026-09-10 | Parts are bought once, in whole-machine quantities, from LCSC (about 87 USD for 2,000 transistors and everything else) rather than per order from DigiKey (218 USD for one board set). | D026 | 2026-09-10 | Nothing is committed to this repo without Nikola's say-so. Drafts live in the working tree. | The public history is curated. | |
| D027 | 2026-09-10 | Design work is committed as it is built, in coherent units; shopping lists, vendor carts and their revisions are never committed (supersedes D026). | The git log feeds the public story; carts are noise in it. | |
| D028 | 2026-09-10 | Header pins 57/58 are named WRL/WRH, not PWL/PWH. | `pwl` is an ngspice keyword; a net called PWL cannot be probed in the machine simulation. Found the first time the whole-machine deck ran. | First bug found by the machine deck, before a single board existed. |
| D029 | 2026-09-10 | The sequencer's registers: IR holds the 4-bit opcode; an 8-bit operand register takes M3..0 at II and all of M at OPI; only ADD and SUB latch the flags; one-word instructions skip S2. | Writing the emulator forced the choices the ISA text left open. Fewer flip-flops than an 8-bit IR plus an 8-bit operand register. | "The emulator is the spec" post. |
| D030 | 2026-09-10 | Design v2, instruction set: opcode 0000 is a family whose operand nibble selects among 16 operand-free instructions (NOP, MOV, XCH, ADD, SUB, OUT, HLT, DEC, INC, LOAD [B], STORE [B], IN, RET, AND, OR, XOR); LDI, JMP, JC, JZ, LOAD n, STORE n, CALL keep their own opcodes; eight opcodes free. | Seven of the sixteen opcodes were spent on instructions that ignore their operand. | D031 | 2026-09-10 | The four spare header pins become ONE (ALU uses 1 for B), F0/F1 (ALU function: add, and, or, xor) and INP (panel switches drive the bus). No spares remain. | Everything the ISA can ever ask of the ALU and the panel has to cross the header now; those two boards are not respun. | |
| D032 | 2026-09-10 | One fab order for every board, after all of them pass the machine gate; no separate order 1 and 2, and the data memory board is designed now, not after a working machine. | Nikola: nothing forces a two-stage build; the machine simulation is the gate, not a first fab. The coupon ships in the same order, so its measurements confirm rather than precede. | |
| D033 | 2026-09-10 | Every board is simulated at a fourth corner, MIX, where each transistor gets a random threshold model, and all flip-flops use a two-phase non-overlapping clock. | A master-slave latch made of parts with different thresholds can become transparent for a moment at the clock edge; identical-corner runs cannot see it. The two-phase clock removes the hazard by construction. | "Why my registers need a clock with a gap in it." |
| D034 | 2026-09-10 | A, B and OUT have no reset; the machine gate compares a register only from the tick after the program first writes it, and programs must not read a register before writing it. | The latches power up in whatever state their parts fall into (the mixed-threshold runs land anywhere); a reset line for them would cost 24 transistors and buy nothing a program needs. | |
| D035 | 2026-09-10 | The sequencer is two boards: 03 (step counter, IR, OPR, flags, decoders, diode matrix; 524 transistors) and 09 (program counter and return register; 416 transistors), joined by a 12-pin link cable carrying OPR7..0, PCR and RAI. The matrix has a row per instruction for S3 and S4 rows only for the four memory accesses (37 rows), and IR, OPR, RA and the flags are transparent latches enabled by their load line AND PH1 rather than full flip-flops. | The registers board taught us the tile density: 200 mm^2 per transistor, so one 1,000-transistor sequencer would have been half a metre square, beyond what the fab takes. Half-latches halve the transistor count where a value is stable for the whole tick and never read while it loads. | "A CPU's control unit is 83 diodes" post. |
| D036 | 2026-09-10 | The clock is a source-coupled Schmitt trigger (two 2N7000s sharing a source resistor) around an RC, read at the second transistor's drain, with a pot for speed, a RUN/STEP switch, a halt gate and a power-on reset. | Three oscillators failed in simulation first: two inverters around an RC settle at a stable operating point, a MOSFET astable falls into its both-on state, and reading the Schmitt pair at the first drain lets the outer loop settle half way. Each was found by the mixed-threshold corner. The shared source resistor makes both trip points move with one transistor's threshold, so the hysteresis survives any part. | "Four clocks that did not tick" post. |
| D037 | 2026-09-10 | Every write into state that is held by a transparent latch or a memory cell is gated by PH1: the load line AND PH1. The memory write lines are WR = slot AND MI AND PH1, and the shared MI inverter has a 4.7k pull-up so the sixteen write lines drop within microseconds of the clock edge. | The first memory board enabled the write with MI alone. At the tick boundary the bus data changes while MI is still dropping through a 22k pull-up, so for a few microseconds the write stacks saw the next tick's bus with the write still on and flipped cells. TYP passed; the mixed-threshold corner and the new memory testbench (bus and controls switching at the same instant) failed. | "The bug the mixed corner found" post: a hold-time race in a memory with no clock input. |
| D038 | 2026-09-10 | The machine is a freestanding column: 2020 aluminium extrusion, four 900 mm uprights on a 500 mm square, boards standing on the four faces on rails and M3 T-nuts, LEDs out, hub flat inside at mid-height, ribbons folded over each board's top edge into the interior. docs/mounting.md and docs/mounting/column.html. | Nine board sizes and an apartment: a wall panel is 1.2 x 0.8 m of something to own, a flat stack hides every LED, a card cage too. | D039 | 2026-09-10 | The program memory board has two 64-way bus headers wired in parallel, so pages daisy-chain along a face with short ribbons and only the first page runs a cable to the hub. | The hub's eight connectors are all one bus; a slot is a place to plug in, not a port. | D040 | 2026-09-10 | The sequencer's control matrix has a diode pad pair at every crossing, unpopulated where the design has no diode, and the eight free opcodes get an S4 row as well as S3. | The silk said "add an instruction: add diodes" and the copper could not do it: a crossing with no diode had no pads.
