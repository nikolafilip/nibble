Multiply and divide on the discrete-transistor calculator

The 4-bit add/subtract calculator now multiplies and divides. The new logic sits on its own sheet, re-uses the existing 3-bit adder, and is proven by simulating the netlist that kicad-cli exports from the project, exactly as KiCad would hand it to ngspice.

How it works

Operands stay 3-bit keypad values (1..7, no key = 0). A 6-bit work register P and a one-hot sequencer L → T1 → T2 → T3 → DN drive the root sheet's adder through two operand muxes:

  • MUL (shift-add, LSB first): P[2:0] ← A, then three times P[5:3] ← P[5:3] + (P0 ? B : 0) and shift right. Product lands in P[5:0], up to 49.
  • DIV (restoring): P[2:0] ← A, then three times shift left, subtract B from the partial remainder using the adder's existing subtract path, keep the difference if it did not go negative. Quotient in P[2:0], remainder in P[5:3]. B = 0 raises the DIV0 flag.
  • The memory register keeps its old behaviour for ADD/SUB and is clocked once, through a glitch-free latch-based clock gate, after DN for MUL/DIV. Two new bits OUT_B4, OUT_B5 extend it to 6 bits.

Inside one multiply and one divide

Two bugs found in the original add/subtract path

Both were invisible with the sim stimulus the project shipped with (2 − 5), and both appear when A ≥ B in subtract mode.

  • The sign-magnitude converter XORed the sum with SUB instead of with the sign flag, so 7 − 5 stored 13. Fixed by driving those three XOR gates from a buffered sign (SIGB).
  • The adder's carry-out (the "no borrow" indicator) leaked into result bit 3, so 6 − 6 stored 8. Fixed by masking bit 3 with ¬SUB in the new result mux.

What changed in the project

New sheets

  • muldiv.kicad_sch: 273 gate cells, generated from one gate list, each drawn in the sheet's own style (10k base, 22k pull-down, 4.7k or 2.2k pull-up, stacked NPN = NAND, parallel NPN = NOR). Connectivity is by global labels; every cell is annotated with its function.
  • testbench.kicad_sch: clock, keypad, op-code and START sources plus the .tran and .ic directives, so the simulator can be run from inside KiCad.

Root sheet edits

  • Encoder output inverters for A0..A2 and EB0..EB2 removed; the operand muxes on the new sheet drive those nets.
  • Memory register D inputs renamed REG_D0..3 / REG_DS; clock source moved to the test bench; MEMCLK is gated.
  • Keys Y2 and X5 restored as inputs (they were hard-wired to +5V); key and sum labels made global.
  • Pull-ups on S0..S3 and OUT_B0/OUT_B1 changed 4.7k → 2.2k (the memory bits sat at 1.2 V with 13 decoder loads).

Untouched: the PCB, the 4-to-16 decoder, the keypad encoders, the adder itself.

Inspect > Simulator > Run    (.tran 1u 9.3m comes from the TESTBENCH sheet)
Plot: OUT_SIGN, OUT_B5 .. OUT_B0, DIV0   and for the internals: L, T1, T2, T3, DN, P5 .. P0, MEMCLK

Op-code: OP1 OP0 = 00 ADD, 01 SUB, 10 MUL, 11 DIV. For MUL/DIV, raise START for one clock; the answer is in memory five clocks later.
